# Verta (ModelDB)

> Verta was an MLOps model-management and experiment-tracking platform (verta.ai), acquired by Cloudera on 2024-06-03; verta.ai now redirects to Cloudera Machine Learning. The open-source ModelDB project (Apache-2.0, github.com/VertaAI/modeldb) remains the maintained surface: ML model versioning, metadata, and experiment management. The REST API is a grpc-gateway transcoding of the ModelDB/UAC gRPC services, served under basePath /v1 with JSON bodies.

## APIs
- [ModelDB REST (grpc-gateway)](https://github.com/VertaAI/modeldb): 11 services, 264 operations under /v1 (Project, Experiment, ExperimentRun, Dataset, Registry, Versioning, Stage, MonitoredEntity, UAC/Authz, SCIM).
